# Aetherion

A Godot 4 GDScript magitech action RPG set in Aetheris, following **The Seven Fractures Saga**.

## Sprint 001

The movement foundation includes a 640×360 viewport, keyboard controls, run/jump/double jump, coyote time, jump buffering, one-way platforms, camera tracking, respawn and a debug overlay. Art is placeholder geometry.

Open `Aetherion/project.godot` in the standard Godot editor and press **F5**.
