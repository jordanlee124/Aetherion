## Established direction

- Title: **Aetherion**. Storyline: **The Seven Fractures Saga**.
- World: **Aetheris**. Energy: **Aether**. Planetary network: **Aether Lattice**.
- Player identity: **Resonant**. Endgame title: **Lattice Warden**.
- 2D magitech action RPG, chibi pixel art, fast side-scrolling combat and deep boss-gated progression.
- Windows and desktop browsers; single-player first. Godot 4 and GDScript.
- Starting town: **Cinderhaven**. The former skyport is **Skyreach Citadel**; Aetherion is the game title.
- First playable combat prototype is planned around the **Vanguard**. Sprint 001 uses a geometric stand-in.

## Seven Fractures progression

| Region | Boss | Permanent unlock |
| --- | --- | --- |
| Cinderhaven | The Runaway Automaton | Resonance Core |
| Verdant Circuit | Sylvaris, the Ironbloom Guardian | Resonance stabilization |
| Luminforge Depths | Magmor, the Furnace Colossus | Advanced equipment enhancement |
| Skyreach Citadel | Commander Vael, the Skybreaker | Advanced class abilities |
| Null Archives | ARCHON-07 | Arcane Circuit customization |
| Fractured Expanse | Seraphine, the Fractured Sovereign | Transcendent resonance |
| The Origin Engine | EIDOLON, the First Architect | Lattice Warden endgame |

The player starts by destroying machines to save people and learns to understand them to save the world. Arcane Engines drain the Lattice; Protocol Zero is a restoration command. Professor Elara Voss of the Lumen Order investigates the player's resonance. Preserve the full recovered [story progression](Seven_Fractures_recovered.md) when designing later content.

## Sprint 001 boundary

The movement prototype is a test yard in Cinderhaven, not a completed town or story chapter. It adds no lore, boss rewards, combat rules, class balance, item systems or story changes. Numerical movement settings are provisional implementation tuning, documented in [Sprint 001](Sprint_001.md).
